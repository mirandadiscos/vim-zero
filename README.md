# VIM ZERO: Do Básico ao IDE com Vim

Bem-vindo a este repositório de conhecimento! O objetivo desta documentação é ser um guia completo e pedagógico para qualquer pessoa que queira não apenas aprender a usar o Vim, mas também a transformá-lo em um ambiente de desenvolvimento (IDE) moderno e produtivo, integrado com as melhores ferramentas de linha de comando.

Este guia foi estruturado para levar você do zero ao nível de um usuário avançado, cobrindo desde os conceitos fundamentais do Vim até a configuração de um ambiente de desenvolvimento completo com plugins, depuração e um terminal otimizado.

---

## Ordem de Leitura Sugerida

Para uma melhor experiência de aprendizado, recomendamos seguir a ordem dos documentos abaixo. Cada um se baseia nos conceitos introduzidos no anterior.

1.  **[Introdução ao Vim: Por que e Como Funciona](./introducao.md)**
    *   Comece aqui. Este documento explica a filosofia da edição modal, a "linguagem" do Vim e os conceitos fundamentais que o tornam uma ferramenta tão poderosa.

2.  **[Guia de Comandos do Vim](./vim_cheatsheet.md)**
    *   Com os conceitos em mente, este é o seu guia de referência prática. Ele lista os comandos essenciais, organizados por nível de proficiência, do modo de sobrevivência ao "mágico".

3.  **[Guia de Plugins para Vim](./vim_plugins.md)**
    *   Aprenda a estender o Vim. Este guia apresenta os gerenciadores de plugins (com foco no `vim-plug`) e uma lista de plugins essenciais para melhorar a experiência de edição.

4.  **[Guia de Instalação e Otimização do `fzf`](./fzf_installation.md)**
    *   `fzf` é uma ferramenta de "fuzzy finding" que irá sobrecarregar sua produtividade. Este guia mostra como instalá-lo e otimizá-lo para buscas de arquivos extremamente rápidas.

5.  **[Guia: Transformando o Vim em um IDE com CoC](./vim_ide.md)**
    *   O coração da documentação. Aprenda a usar o `coc.nvim` (Conqueror of Completion) para adicionar inteligência de código (LSP), autocompletar, diagnósticos e até mesmo depuração, transformando o Vim em um IDE completo.

6.  **[Guia: Vim vs. Neovim (Nvim)](./neovim_explained.md)**
    *   Com um ambiente Vim funcional, explore o "próximo passo". Este documento explica o que é o Neovim, suas vantagens (LSP nativo, configuração em Lua) e como migrar do Vim.

7.  **[Guia: Terminais para Windows para WSL e Vim](./windows_terminals.md)**
    *   Se você é um usuário de Windows, um terminal moderno é essencial. Este guia apresenta as melhores opções (com foco no Windows Terminal) e explica como configurá-las para uma experiência visual perfeita.

8.  **[Guia: Configurando seu Terminal para Produtividade](./terminal_configs.md)**
    *   Otimize o ambiente que envolve o Vim. Aprenda a configurar seu shell (`zsh` com `Oh My Zsh`), criar aliases, usar plugins de terminal e gerenciar variáveis de ambiente de forma profissional com `direnv`.

9.  **[Guia de Comandos Linux para Desenvolvedores](./linux_commands.md)**
    *   Aprofunde seu conhecimento em Linux com esta coleção de comandos essenciais para manipulação de arquivos, processamento de texto, monitoramento de sistema e rede.

10. **[Guia: Gerenciando Dotfiles com Git e GitHub](./dotfiles_management.md)**
    *   Aprenda a versionar e fazer backup de suas configurações (`.vimrc`, `.zshrc`, etc.) usando Git e GitHub, garantindo portabilidade e um ambiente de desenvolvimento consistente.

11. **[Guia Extra: Usando Vim + Gemini para Superprodutividade](./vim_gemini.md)**
    *   Leve seu fluxo de trabalho a um novo patamar. Aprenda a integrar o poder de uma IA como o Gemini diretamente com o Vim para gerar, explicar e refatorar código sem sair do terminal.
