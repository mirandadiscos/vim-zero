# VIM ZERO: Do Básico ao IDE com Neovim e Ferramentas Essenciais

Bem-vindo a este repositório de conhecimento! O objetivo desta documentação é ser um guia completo e pedagógico para qualquer pessoa que queira não apenas aprender a usar o Vim/Neovim, mas também a transformá-lo em um ambiente de desenvolvimento (IDE) moderno e produtivo, integrado com as melhores ferramentas de linha de comando.

Este guia foi estruturado para levar você do zero ao nível de um usuário avançado, cobrindo desde a configuração do terminal até a personalização de um ambiente de desenvolvimento completo com Neovim.

---

## Ordem de Leitura Sugerida

Para uma melhor experiência de aprendizado, recomendamos seguir a ordem dos documentos abaixo. Cada um se baseia nos conceitos introduzidos no anterior.

### Parte 1: Fundamentos do Ambiente de Linha de Comando

1.  **[Configuração do Terminal](./01_terminal_setup.md)**
    *   O primeiro passo para uma experiência de desenvolvimento produtiva. Aprenda a configurar seu terminal, com foco no `Oh My Zsh` e em como criar um ambiente visualmente agradável e funcional.

2.  **[Comandos Essenciais do Linux](./02_linux_commands.md)**
    *   Um guia de referência para os comandos de linha de comando que todo desenvolvedor deve conhecer. Essencial para manipulação de arquivos, processos e automação.

### Parte 2: De Vim a Neovim

3.  **[Introdução ao Vim e Neovim](./03_vim_neovim_intro_basics.md)**
    *   Comece aqui. Entenda a filosofia da edição modal, a "linguagem" do Vim e os conceitos fundamentais que o tornam uma ferramenta tão poderosa.

4.  **[Instalação e Filosofia do Neovim](./04_neovim_installation_philosophy.md)**
    *   Com os conceitos em mente, este guia foca no Neovim: por que usá-lo, como instalá-lo e as vantagens de sua arquitetura moderna (LSP nativo, Lua).

### Parte 3: Transformando o Neovim em um IDE

5.  **[Gerenciamento de Plugins com `lazy.nvim`](./05_neovim_plugin_management.md)**
    *   Aprenda a estender o Neovim com um gerenciador de plugins moderno. Este guia apresenta o `lazy.nvim` e os plugins essenciais para uma experiência de edição aprimorada.

6.  **[Neovim como um IDE com LSP](./06_neovim_as_ide.md)**
    *   O coração da documentação. Aprenda a usar o LSP nativo do Neovim para adicionar inteligência de código, autocompletar, diagnósticos e muito mais.

### Parte 4: Produtividade e Dotfiles

7.  **[Ferramentas de Produtividade e Dotfiles](./07_productivity_dotfiles.md)**
    *   Aprenda a gerenciar suas configurações (`dotfiles`) com Git e a usar ferramentas como `fzf` e `direnv` para otimizar seu fluxo de trabalho.
